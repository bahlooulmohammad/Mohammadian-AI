# Mohammadian AI — میز آماده‌سازی ریلز (بدون اتصال متا)

این نسخه برای آماده‌سازی و نگهداری محتوای ریلز طراحی شده است؛ **به فیسبوک یا Meta وصل نمی‌شود و انتشار خودکار در اینستاگرام انجام نمی‌دهد.** کاربر هر روز بسته محتوایی را در ChatGPT دریافت می‌کند، ویدئوی مجاز را در پنل ذخیره می‌کند و خودش در اپ اینستاگرام دکمه Share را می‌زند.

## امکانات
- پنل فارسی و ورود با رمز
- بارگذاری ویدئوی MP4/MOV (حداکثر ۲۵۰ مگابایت)
- نگهداری کپشن، هشتگ، لینک منبع و توضیح مدرک مجوز بازنشر
- تنظیم تاریخ و ساعت یادآوری برای هر ریلز (پیش‌فرض ساعت ۲۰:۰۰)
- فهرست محتواهای آماده و علامت‌گذاری پس از انتشار دستی
- بدون توکن، اپ Meta، اتصال فیسبوک یا روش‌های غیررسمی ورود به اینستاگرام

## اجرای محلی روی کامپیوتر
1. Node.js نسخه ۲۰ یا جدیدتر نصب باشد.
2. ZIP را استخراج کنید و در پوشه پروژه ترمینال باز کنید.
3. اجرا کنید: `npm install`
4. فایل `.env.example` را به `.env` کپی کنید.
5. `ADMIN_PASSWORD` را با رمز طولانی و منحصربه‌فرد و `SESSION_SECRET` را با یک مقدار تصادفی طولانی عوض کنید.
6. اجرا کنید: `npm start`
7. در مرورگر باز کنید: `http://localhost:3000`

## آنلاین‌کردن
برای استفاده از بیرون کامپیوتر، باید پروژه روی یک میزبان Node.js با HTTPS مستقر شود. برای نگهداری فایل‌ها، میزبان باید فضای ذخیره‌سازی پایدار داشته باشد؛ دیسک موقت بعضی سرویس‌های رایگان ممکن است فایل‌ها را پاک کند. فایل `.env` را هرگز در Git یا چت قرار ندهید.

## نکات مهم و محدودیت‌ها
- این پنل خودش ویدئو از اینترنت جمع‌آوری نمی‌کند؛ بسته روزانه ایده، کپشن و پیشنهاد منبع در گفت‌وگوی ChatGPT زمان‌بندی شده است. برای افزودن جست‌وجوی خودکار منابع به خود برنامه، باید منبع داده/API مناسب و بررسی مجوز محتوا جداگانه پیاده‌سازی شود.
- از ویدئو فقط وقتی استفاده کنید که خودتان مالک آن هستید یا اجازه روشن بازنشر دارید. ذکر نام صاحب اثر به‌تنهایی مجوز نیست.
- این پنل به Insights خصوصی اینستاگرام دسترسی ندارد. برای تحلیل آمار، داده یا تصویر Insights را دستی ارائه کنید.
- یادآوری ChatGPT ساعت ۲۰:۰۰ در منطقه زمانی انتخاب‌شده در تنظیم زمان‌بندی انجام می‌شود؛ پنل وب به‌تنهایی اعلان موبایلی تضمین‌شده ندارد.
- نسخه فعلی برای یک مدیر و استفاده سبک است؛ پیش از استفاده عمومی باید ذخیره‌سازی پایدار، پشتیبان‌گیری و مدیریت نشست‌ها متناسب با میزبان تنظیم شود.

## اجرای سریع
- ویندوز: روی `شروع-برنامه-ویندوز.bat` دوبار کلیک کنید. اجرای اول فایل `.env` را می‌سازد؛ رمز مدیریت و کلید نشست را تغییر دهید و دوباره فایل را اجرا کنید.
- مک/لینوکس: در ترمینال `./start-linux-mac.sh` را اجرا کنید. اجرای اول `.env` را می‌سازد؛ آن را ویرایش کنید و دوباره اجرا کنید.
- برای باز کردن پنل روی همان دستگاه: `http://localhost:3000`
- برای باز کردن از گوشی در همان وای‌فای: در مرورگر گوشی به‌جای localhost، نشانی IP محلی کامپیوتر را با `:3000` وارد کنید. این روش فقط در شبکه محلی است و پنل را به اینترنت عمومی نمی‌برد.

## وضعیت تکمیل
کد این نسخه برای کار محلی آماده است و بررسی نحوی Node.js روی فایل سرور انجام شده است. برای آنلاین شدن عمومی باید مالک حساب میزبانی، پروژه را به سرویس میزبانی Node.js وصل و متغیرهای محیطی را آنجا تنظیم کند. این مرحله بدون ورود و تأیید صاحب حساب انجام نمی‌شود. برای میزبانی، فضای ذخیره‌سازی پایدار لازم است تا ویدئوها بعد از راه‌اندازی مجدد حذف نشوند. تا قبل از انجام این مراحل، برنامه را آنلاین یا همیشه‌در‌دسترس فرض نکنید.
